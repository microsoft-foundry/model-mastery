# Self-guided workshop

Work through the steps in order. Each one opens with a **developer question** —
the exercise is the answer. Together they tell one story: you can't say an agent
is *better* until you can measure how *good* it is.

| # | Step | Where | Time |
|---|------|-------|------|
| 0 | [Getting started](00-getting-started.md) | VS Code | before you start |
| 1 | [Set up and validate](01-setup-and-validate.md) | VS Code + Portal | 15 min |
| 2 | [Select the right model for the task](02-model-selection.md) | Portal | 30 min |
| 3 | [Build TrailMate](03-build-trailmate.md) | VS Code | ~10 min |
| 4 | [Test and observe](04-test-and-observe.md) | Portal | ~6 min |
| 5 | [Measure a baseline](05-baseline-eval.md) | Portal | ~8 min |
| 6 | [Improve the model with Model Router](06-model-router.md) | VS Code + Portal | ~8 min |
| 7 | [Improve the agent with Agent Optimizer](07-agent-optimizer.md) | Portal | ~8 min |
| 8 | [Compare and promote](08-compare-and-promote.md) | Portal | ~5 min |

Total: about 90 minutes.

You'll build **TrailMate**, a grounded product expert for Contoso Outdoors, then
climb the hill: measure a baseline, change one lever at a time (model, then
instructions), and promote the version the evidence supports.
